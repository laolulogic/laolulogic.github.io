The challenge

Each new acquisition had to land under the correct LLC, in the correct pipeline stage, with the spreadsheet updated to match. One slip meant wrong reporting.

What I built

  1. Custom JavaScript that cleans and normalizes the incoming data
  2. A Follow Up Boss lookup that checks whether the LLC already exists
  3. Seven branching paths that create the LLC if needed, then the right deal
  4. Matching Google Sheets updates on every path
